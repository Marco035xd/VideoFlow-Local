Descargas retiradas temporalmente

El plazo cuenta desde que retiras cada descarga. Al guardar, se aplica también a los registros temporales existentes. Los que superen el plazo se eliminarán de este apartado; los archivos y el historial se conservan.

En modo incógnito, los registros solo duran esta sesión, aunque elijas un plazo mayor.

Conexión y recuperación

Se comprobará FFmpeg al iniciar la aplicación.

Buscando información de versiones…

La búsqueda se realiza en segundo plano en cada inicio. Las versiones nuevas se descargan desde el proveedor de FFmpeg para Windows.
Abrir descarga oficial

Si el video abre en el navegador pero la descarga agota el tiempo de espera, prueba IPv4 o IPv6 y guarda la configuración. Automática renueva el enlace una vez mediante IPv4 tras un fallo de conexión; 0 reintentos desactiva esa recuperación.

Cuando el enlace incluye servidores alternativos de YouTube, se prueban hasta dos si el principal no responde. Se conserva el mismo formato y la pista de audio. 0 reintentos desactiva el cambio de servidor.

Estos valores se aplican a las nuevas descargas. Las conversiones comparten el límite de trabajos simultáneos.
