# VideoFlow Local 1.0.0 para Windows

Descarga **VideoFlow-Local-1.0.0-Setup-x64.exe**, ejecútalo y sigue los pasos del instalador. Compatible con Windows 10 y 11 de 64 bits.

## Incluye

- Instalación para el usuario actual, acceso desde el menú Inicio y acceso directo opcional en el escritorio.
- Python, FFmpeg, FFprobe y Deno incluidos; no hace falta instalarlos por separado.
- Ventana de inicio de VideoFlow y la interfaz completa en el navegador.
- Descargadores de YouTube, Facebook y TikTok, selección de calidad, video o audio y Guardar como.
- Historial de enlaces con opción de volver a descargar y una carpeta de destino independiente para cada plataforma.
- Historial y preferencias en `%LOCALAPPDATA%\VideoFlowLocal\data`, conservados al actualizar mediante otro instalador.
- Desinstalación desde Configuración de Windows.

Se comprobó el ejecutable con las herramientas incluidas, el análisis de las tres plataformas y descargas reales de video y audio. No se comprobó la instalación interactiva.

El instalador no tiene firma digital. `SHA256SUMS.txt` contiene la huella del archivo publicado.
